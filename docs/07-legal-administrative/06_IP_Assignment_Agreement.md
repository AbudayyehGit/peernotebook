Assignor hereby unconditionally and irrevocably sells, assigns, transfers, conveys, and delivers to Assignee, its successors, and assigns, all worldwide right, title, and interest in and to any and all:

1. **Source Code & Software Repositories:**
   * All frontend source code, user interface components, and styling configurations (React 18, Vite 6, Tailwind CSS 4).
   * All client-side storage schemas, IndexedDB tables, and local encryption implementations (`Dexie.js`, `WebCrypto API`, AES-GCM primitives).
   * All cloud relational database definitions, PostgreSQL DDL schemas, Row-Level Security (RLS) policies, and Supabase integration scripts.
   * All background synchronization workers (`syncWorker.ts`), offline queue processors, collision detection routines, and retry state machines.

2. **Domain Names & Web Properties:**
   * `peernotebook.com`
   * `www.peernotebook.com`
   * All associated DNS configurations, Vercel Edge routing rules, SSL/TLS certificates, and related subdomains.

3. **Master Documentation Binder & Technical Specifications:**
   * The complete 27-document Master Documentation Binder organized under categories `01-project-management` through `07-legal-administrative`.
   * The GA #8 Production Architecture White Paper, STRIDE Threat Model, and System Architecture data flow specifications.
   * All engineering runbooks, disaster recovery protocols, and SRE observability standards.

4. **Clinical, Regulatory & Billing Algorithms:**
   * The proprietary CalAIM & Medi-Cal HCPCS **H0038** 15-minute billing unit calculation engine adhering to CMS 8-minute rounding rules.
   * The 3-way time allocation tracking logic (Direct Face-to-Face, Travel, and Documentation minutes) for Place of Service (POS) 15, 11, and 02.
   * The automated 4-part non-clinical encounter note validation engine (Recovery Goal, Intervention, Client Response with Verbatim Quotes, Next Steps).
   * The CalMHSA 17 Core Peer Competency taxonomy, interactive tag mappings, and non-clinical terminology guardrails.
   * The client-side PDF export compiler and tamper-evident SHA-256 cryptographic sealing algorithm.

5. **Trademarks, Trade Dress & Branding:**
   * The mark **Peer Notebook®** and all associated logos, icons (including the HeartHandshake brand mark), and wordmarks.
   * The trauma-informed clinical color system and trade dress: Soft Slate (`#F8FAFC`), Deep Navy (`#1E3A8A`), Muted Teal (`#0F766E`), Forest Green (`#16A34A`), and Warm Amber (`#D97706`).

6. **Inventions, Trade Secrets & Know-How:**
   * All trade secrets, methods, processes, design tokens, formulas, and confidential information related to peer support workflow optimization.
